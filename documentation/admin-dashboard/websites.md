# Admin Dashboard: Websites

## Purpose

The Websites module enables administrators to review hosted projects, suspend or unsuspend them, and perform destructive cleanup.

## Primary Controller

- `app/Controllers/AdminController.php`
- `app/Controllers/PublishController.php`

## Key Actions

- `websites()` displays all websites and owner details.
- `suspendWebsite()` updates status to `suspended` and removes public files.
- `unsuspendWebsite()` returns a site to `draft` status.
- `deleteWebsite()` removes the website record, unpublishes the site, and deletes project storage.

## Business logic

- Suspension and deletion both call `PublishingService::unpublish()` to remove public copies.
- The sitemap is regenerated after site state changes via `SitemapGenerator::writeToFile()`, but failures are intentionally non-fatal.
- Website deletion triggers `ProjectStorageService::deleteProjectDirectory()` to remove draft assets.

## Data model

- Website projects are stored in `websites`.
- Public URLs are generated by `PublicSiteUrlService`.
- Admin views are populated using `AdminRepository::websites()`.

## Resilience

- Failures during sitemap regeneration are caught and logged implicitly so admin workflows are not blocked.
- `unpublish()` may be invoked from admin actions as well as user publish/unpublish workflows.
