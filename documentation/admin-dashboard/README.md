# Admin Dashboard Documentation

This folder contains engineering documentation for the TurboHostMw admin and dashboard modules.

Files:
- `users.md` — Administrator user account management workflows.
- `websites.md` — Hosted website project controls.
- `media.md` — Media upload and branding asset management.
- `payments.md` — Premium checkout and payment lifecycle.
- `reports.md` — Abuse reports and review operations.
- `notifications.md` — System notification broadcasting and delivery.
- `profile.md` — User profile, password, and email management.
- `legal.md` — Policy content, versioning, publishing, and acceptance.
- `settings.md` — Platform settings persistence and admin configuration tabs.
